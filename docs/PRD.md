# Block Blast 스타일 블록 퍼즐 게임 - PRD (Product Requirements Document)

## 1. 프로젝트 개요

### 1.1 목적
광고 없는 모바일 친화적인 웹 기반 블록 퍼즐 게임을 개발하여 사용자에게 끊김 없는 게임 경험을 제공

### 1.2 목표
- 📱 모바일 퍼스트 반응형 웹 애플리케이션
- 🚫 완전한 광고 없는 경험
- 🎮 직관적이고 중독성 있는 게임플레이
- ⚡ 빠른 로딩 및 부드러운 애니메이션
- 💾 로컬 저장을 통한 진행 상황 저장

### 1.3 대상 사용자
- 주요: 모바일 사용자 (iOS, Android)
- 부가: 데스크톱/태블릿 사용자
- 연령대: 전 연령 (특히 10-50세)

## 2. 게임 메커니즘

### 2.1 핵심 게임플레이

#### 게임 보드
- **크기**: 8x8 그리드 (64개 셀)
- **디스플레이**: 
  - 모바일: 화면 너비의 90% 활용
  - 데스크톱: 최대 500px 정사각형
- **셀 크기**: 동적 조정 (뷰포트 기준)

#### 블록 시스템
**블록 제공 영역**:
- 하단에 3개의 블록 동시 제공
- 블록 사용 시 즉시 새 블록으로 교체
- 3개 모두 배치 불가능할 경우 게임 오버

**블록 타입** (총 19종):
1. **1x1 블록**: 단일 셀
2. **2x2 블록**: 2x2 정사각형
3. **3x3 블록**: 3x3 정사각형
4. **라인 블록**:
   - 수평 2칸, 3칸, 4칸, 5칸
   - 수직 2칸, 3칸, 4칸, 5칸
5. **L자형 블록** (4가지 회전):
   - L 모양 (좌하단)
   - 역 L 모양 (우하단)
   - 회전 L 모양 (좌상단)
   - 회전 역 L 모양 (우상단)
6. **T자형 블록**:
   - 작은 T (3칸)
   - 큰 T (5칸)
7. **특수 블록**:
   - 지그재그 (Z형)
   - 계단형

### 2.2 게임 규칙

#### 블록 배치
1. 드래그 앤 드롭 (모바일: 터치 앤 드래그)
2. 블록은 회전 불가
3. 빈 공간에만 배치 가능
4. 일부만 걸치는 배치 불가
5. 배치 시 시각적 피드백 (유효/무효 위치 표시)

#### 점수 시스템
- **블록 배치**: 사용한 셀 수 × 1점
- **라인 제거** (행 또는 열):
  - 1줄: +10점
  - 2줄 동시: +30점 (10+20)
  - 3줄 동시: +60점 (10+20+30)
  - 4줄 동시: +100점 (10+20+30+40)
  - 5줄 이상: n줄 * (n줄 * 5) 보너스
- **콤보 보너스**: 연속 라인 제거 시 +10점/콤보

#### 라인 제거
- 가로줄 8칸 또는 세로줄 8칸이 모두 채워지면 제거
- 동시에 여러 줄 제거 가능 (십자 제거)
- 제거 시 애니메이션 효과
- 제거된 공간은 즉시 빈 공간으로 전환

#### 게임 오버 조건
- 제공된 3개의 블록 중 어떤 것도 보드에 배치할 수 없을 때
- "Restart" 버튼으로 새 게임 시작 가능

## 3. 기술 요구사항

### 3.1 기술 스택

#### 프론트엔드
- **프레임워크**: React 18+ (Hooks 기반)
- **상태 관리**: React Context API 또는 Zustand
- **스타일링**: 
  - Tailwind CSS (빠른 개발)
  - CSS Modules (컴포넌트별 스타일)
- **애니메이션**: Framer Motion 또는 React Spring
- **번들러**: Vite (빠른 빌드)

#### PWA (Progressive Web App)
- Service Worker 구현
- 오프라인 지원
- 홈 화면 설치 가능
- Manifest.json 설정

#### 호스팅
- **옵션 1**: Vercel (권장)
- **옵션 2**: Netlify
- **옵션 3**: GitHub Pages + GitHub Actions
- HTTPS 필수

### 3.2 성능 요구사항
- **초기 로딩**: < 2초
- **애니메이션**: 60 FPS 유지
- **터치 반응 속도**: < 16ms (모바일)
- **번들 크기**: < 500KB (gzip)

### 3.3 브라우저 지원
- Chrome/Edge (최신 2개 버전)
- Safari (iOS 14+)
- Firefox (최신 2개 버전)
- Samsung Internet
- WebView (모바일 앱 내 브라우저)

### 4.2 색상 팔레트
**라이트 모드** (기본):
- 배경: `#F5F5F7` (밝은 회색)
- 보드 배경: `#FFFFFF` (흰색)
- 빈 셀: `#E8E8EA` (연한 회색)
- 채워진 셀: `#5856D6` (보라)
- 블록 프리뷰: `#34C759` (녹색)
- 유효 위치: `#34C759` 투명도 0.3
- 무효 위치: `#FF3B30` 투명도 0.3
- 텍스트: `#1C1C1E` (검정)

**다크 모드** (선택):
- 배경: `#1C1C1E`
- 보드 배경: `#2C2C2E`
- 빈 셀: `#3A3A3C`
- 채워진 셀: `#5E5CE6`
- 나머지는 라이트 모드와 동일한 색상 사용

### 4.3 애니메이션
1. **블록 드래그**:
   - 들어올리기: scale(1.1), 그림자 효과
   - 유효 위치 hover: 투명도 0.6으로 미리보기
   
2. **블록 배치**:
   - 스냅 애니메이션 (200ms ease-out)
   
3. **라인 제거**:
   - 페이드 아웃 + 스케일 효과 (300ms)
   - 파티클 효과 (선택)
   
4. **점수 증가**:
   - 숫자 카운트업 애니메이션
   - +점수 플로팅 텍스트

### 4.4 터치/드래그 인터랙션
- **터치 시작**: 블록 하이라이트
- **드래그 중**: 
  - 블록이 손가락을 따라 이동
  - 유효한 위치에 반투명 프리뷰 표시
  - 무효한 위치에 빨간색 표시
- **터치 종료**:
  - 유효한 위치: 블록 배치 + 햅틱 피드백
  - 무효한 위치: 블록 원위치 복귀

## 6. 데이터 구조

### 6.1 게임 상태

```typescript
interface GameState {
  board: Cell[][];           // 8x8 2D 배열
  score: number;
  highScore: number;
  currentBlocks: Block[];    // 3개 블록 배열
  gameStatus: 'playing' | 'gameOver';
  combo: number;
}

interface Cell {
  filled: boolean;
  color?: string;
}

interface Block {
  id: string;
  shape: number[][];         // 2D 배열 (1: 채워짐, 0: 비어있음)
  color: string;
}

// 블록 예시
const LBlock: Block = {
  id: 'l-block-1',
  shape: [
    [1, 0],
    [1, 0],
    [1, 1]
  ],
  color: '#5856D6'
}
```

### 6.2 LocalStorage 스키마

```typescript
interface StoredGameData {
  highScore: number;
  lastGameState?: GameState;  // 중단된 게임 복원용
  settings: {
    soundEnabled: boolean;
    hapticEnabled: boolean;
    darkMode: boolean;
  };
  stats: {
    gamesPlayed: number;
    totalScore: number;
    bestCombo: number;
  };
}
```
